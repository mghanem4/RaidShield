# Harmless offline examples

Every dataset in this directory is synthetic and intentionally contains no hate speech, slurs, threats, or targeted abuse.

- `offline_safe_batch.json` is a small neutral reply-thread example for import and context inspection.
- `offline_safe_bot_raid_demo.json` is a larger harmless synchronized burst for coordination and graph testing.

Experimental model rankings are not ground truth and may still surface a harmless comment for review. That behavior is a false-positive/evaluation signal, not evidence that the repository contains harmful material.
